Which knockouts actually matter? One rule, no p-values

specific(k) ⇔ ∀ stimulus s:  |Δs(k)| > maxj |Δs(shamj)|  ∧  sign constant
The model has no noise, so random knockouts are the yardstick. A targeted knockout's effect counts only if it is bigger than every sham's, in the same direction, on every stimulus. Δ = change vs the intact brain.
